## Package Status

This package is ready for public upload review. The paper uses aggregate Montgomery County, Maryland traffic-count tables from 1976 and 1985. The local paper-project folder contains legacy Lotus 1-2-3 workbook files matching those paper tables, and those files have been copied here with modernized spreadsheet and CSV sidecars.

No paper-specific software was identified in the paper text or the paper-project folder. The analysis appears to be spreadsheet aggregation and table calculation rather than a standalone code workflow.
